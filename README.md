🌦️ Projeto Weather API

Link para acesso: https://victorhp21.github.io/SpringBoot-API-Weather/

Este projeto foi criado como uma forma de colocar em prática os conhecimentos que venho adquirindo em Spring Boot, além de testar a integração entre uma API externa de meteorologia e uma interface web simples feita em HTML, CSS e JavaScript.

A ideia é consumir dados reais de clima e exibi-los de forma interativa em um card visual, com previsão para os próximos dias.

O projeto ainda está em desenvolvimento, e deve receber melhorias e novas funcionalidades conforme eu avanço nos estudos e ganho mais experiência com back-end e integração de APIs.

🚀 Tecnologias utilizadas

Java 23

Spring Boot (Uso do Intellij para code)

API externa (Visual Crossing Weather)

HTML, CSS e JavaScript para o front-end

(Opcional) Redis para cache das respostas da API -- ainda preciso descobrir outra forma de uso para não apenas para esta ferramenta mas para hospedagem, no intuito de que o site possa ser hospedado e acessado por terceiros de forma eficiente.
